## 任务基础

每个任务包含以下属性：
- **标题**：简短描述任务内容
- **描述**：详细说明，支持 Markdown 格式
- **优先级**：P0（紧急）→ P3（低优先级）
- **时间**：开始日期和截止日期
- **项目**：归属的项目分组
- **提醒**：到期前提醒设置

## 创建任务

### 快速创建
点击任务页右下角 **+** 按钮，在底部弹出的面板中：
1. 输入标题
2. 选择项目
3. 设置时间（可选）
4. 设置提醒（可选）
5. 点击创建

### 作为子任务创建
在任务详情页，点击子任务区域的 **+** 按钮即可添加子任务。子任务会自动继承父任务的项目。

## 任务树

Taskora 支持无限层级的子任务树。你可以：
- 在任务详情页查看和展开子任务树
- 拖拽调整子任务顺序
- 把任务移到其他父任务下
- 父任务完成条件：所有直接子任务完成后，父任务自动标记完成

## 编辑任务

点击任务进入详情页：
- 点击标题直接编辑
- 描述区支持 Markdown 编辑，包含工具栏（加粗、列表、链接等）
- 可以粘贴/拖拽图片到描述区
- 修改实时保存

## 完成与删除

- **完成**：点击任务前的圆圈勾选，任务标记为完成
- **级联完成**：完成父任务时，所有子任务同步完成
- **删除**：在任务详情页或右滑/右键菜单中删除

## 检查项（Checklist）

每个任务可以添加检查项：
- 在详情页的检查项区域添加
- 勾选完成每一项
- 检查项纳入任务进度计算

## 附件

支持为任务添加文件附件：
- 点击附件区的上传按钮
- 支持图片预览和文件下载
- 附件随任务云同步
