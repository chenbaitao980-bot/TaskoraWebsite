## 导出格式

当前支持导出为 **Excel (.xlsx)** 格式。

## 导出内容

- 任务标题、描述、优先级
- 开始时间、截止时间
- 完成状态
- 所属项目
- 子任务层级（缩进展示）

## 如何导出

1. 进入 **个人中心 → 导出**
2. 选择筛选条件（可选）：
   - 时间范围
   - 指定项目
   - 优先级
3. 点击导出按钮
4. 选择保存位置
