## 日历视图

Taskora 提供完整的日历视图，让你直观看到任务在时间线上的分布。

### 周视图
- 默认展示当前周的任务
- 跨天任务显示为顶部横条
- 单日任务按时间段显示在对应列中
- 支持左右滑动切换周

### 日视图
- 精确到小时的任务排列
- 适合查看某一天的详细安排

## 操作

### 拖拽改期
- 长按任务块，拖拽到新的时间位置
- 小时模式下支持横向拖拽调整时段
- 松手后自动更新开始/截止时间

### 新建任务
- 点击日历空白区域可快速新建任务
- 自动填入对应日期

### 缩放
- Ctrl + 鼠标滚轮缩放时间粒度（桌面端）
