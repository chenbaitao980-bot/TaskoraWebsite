title: 云同步
description: 登录后跨设备同步所有数据。
---

## 同步内容

登录账号后，以下数据自动云同步：
- 项目和分组
- 任务（含子任务树）
- 检查项
- 附件
- 模板节点
- 偏好设置（筛选状态等）

## 同步机制

- **自动同步**：数据变更后自动推送到云端
- **实时订阅**：通过 Supabase Realtime，其他设备的变更实时推送到本机
- **冲突处理**：以最新修改时间为准

## 离线使用

- 断网时数据保存在本地
- 恢复网络后自动同步
- 不会丢失离线期间的修改

## 数据安全

- 使用 Supabase 托管，数据加密存储
- 行级安全策略（RLS），用户只能访问自己的数据
- 不收集隐私敏感信息
