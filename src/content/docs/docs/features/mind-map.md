## 思维导图视图

切换到思维导图模式，任务以树形图方式展示，直观看到任务之间的父子关系。

## 功能

### 节点操作
- **点击节点**：查看/编辑任务详情
- **拖拽节点**：自由调整位置
- **右键菜单**：删除、移动到其他父节点
- **滑动操作**：左滑快速完成/删除

### 连线
- 点击节点右侧的 **+** 图标，拖拽到目标节点建立父子关系
- 连线自动跟随节点位置更新

### 多选
- 按住 Ctrl 点击多个节点可以批量选择
- 框选：Ctrl + 拖拽画选框

### 缩放与平移
- 鼠标滚轮缩放
- 拖拽空白区域平移画布

## 与列表视图切换

在任务页顶部可以切换列表和思维导图视图，数据实时同步。
