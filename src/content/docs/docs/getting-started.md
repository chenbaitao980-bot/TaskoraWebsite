## 下载安装

### Android
1. 前往 [下载页](/download/) 下载 APK 安装包
2. 打开 APK 文件，按提示安装（可能需要允许"未知来源"安装）
3. 安装完成后打开 Taskora

### Windows
1. 前往 [下载页](/download/) 下载 Windows 版本
2. 解压到任意目录
3. 双击 `Taskora.exe` 启动

### Web
直接访问在线版本即可使用，无需安装。

## 注册与登录

1. 打开 Taskora，进入登录页面
2. 支持两种登录方式：
   - **邮箱+密码**：输入邮箱和密码注册/登录
   - **手机号验证码**：输入手机号，接收短信验证码登录
3. 也可以选择**本地模式**：不登录直接使用，数据仅保存在本设备

:::tip[建议登录]
登录后可以跨设备同步任务数据，推荐注册账号使用。
:::

## 创建你的第一个任务

1. 进入**任务页面**
2. 点击右下角的 **+** 按钮
3. 输入任务标题，例如「准备期末考试」
4. 选择所属项目（默认放在收件箱）
5. 设置开始/截止时间（可选）
6. 点击创建

## 用 AI 拆分任务

1. 打开刚创建的任务详情
2. 滚动到底部，找到 **AI 拆分子任务** 区域
3. 点击 **一键拆分子任务**
4. AI 会自动把任务拆解成多级子任务树
5. 你可以编辑、删除或手动添加子任务

:::note[VIP 功能]
AI 智能拆分是 VIP 专属功能。[了解 VIP 会员](/docs/vip/)
:::
