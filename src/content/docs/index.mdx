## 核心功能

<CardGrid stagger>
  <Card title="AI 智能拆分" icon="star">
    把复杂目标交给 AI，自动拆解成层级清晰的子任务树。
  </Card>
  <Card title="日历排程" icon="seti:todo">
    按时间线查看和调整任务，支持拖拽改期。
  </Card>
  <Card title="思维导图" icon="puzzle">
    任务树可视化，支持自由拖拽、连线、分组。
  </Card>
  <Card title="云同步" icon="laptop">
    登录后跨设备同步任务、项目、清单和附件。
  </Card>
  <Card title="智能提醒" icon="warning">
    闹钟式提醒，绕过静音模式，不怕错过重要事项。
  </Card>
  <Card title="数据导出" icon="document">
    导出任务数据为 Excel 文件，方便备份和分析。
  </Card>
</CardGrid>

## 适合谁

- 备考、学习、写作、项目制工作的人
- 需要把长期目标拆成每日行动的人
- 希望用 AI 辅助规划，但仍保留自己控制权的人
